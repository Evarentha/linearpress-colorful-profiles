# 多彩个人资料（colorful-profiles）

LinearPress 增强用户个人资料插件：

- **右上角用户菜单**：头像 + 昵称/@用户名/邮箱 → 「编辑个人资料」 → 其他插件项（如高级用户管理的「个人设置」）。
- **资料编辑页** `/profile/edit`：用户名（只读）、昵称、邮箱、头像、网站、描述（Markdown）、联系方式、代表作；保存二次确认；改邮箱时侵入式提示。
- **头像**：文件上传 + PC/触屏兼容的正方形裁剪；支持 GIF 动态与 APNG（可配置开关）；原图无损存储（裁剪以坐标 + CSS 呈现，动画不会被破坏）；默认限制画面 ≤1024×1024、文件 ≤10MB；上传路径 `./uploads/avatars/`；若安装了 media-library 可从媒体库选择。
- **邮箱重验证**：接入 advanced-user-management——更改邮箱后置为未验证并发送验证邮件（复用 AUM 的 SMTP 配置与 `/verify` 路由），验证前无法发布文章/评论。
- **公开资料页** `/user/:username`（需登录）：昵称、用户名、邮箱、头像、网站（自动链接）、Markdown 描述、代表作、最近文章**按月时间线**（lazyload，单次数量可配置）。
- **头像展示位**：文章作者左侧、评论作者左侧、右上角名称左侧、展开菜单内。

## 依赖

| 插件 | 用途 | 缺失影响 |
| --- | --- | --- |
| advanced-comments | 评论视图/评论表单（本插件覆盖文章页并保留其功能） | 文章页不显示评论系统 |
| advanced-user-management | 邮箱验证状态（`aum_users`）与 SMTP 配置 | 邮箱变更不再强制重验证 |

两者未启用时插件仍可激活（部分功能降级，日志输出警告）。建议加载顺序晚于二者（本插件在 `activate` 阶段注册视图目录，覆盖 `layouts/web.ejs` 与 `web/post.ejs`）。

## 开发

```bash
# 在 base 目录开发（插件位于 base/src/plugins/colorful-profiles，与本目录保持同步）
npm run typecheck
npm run dev
```

## 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 用户名 | 只读 | 登录凭据之一，不可修改 |
| 昵称 | 单行 | 非空时全站替代用户名显示 |
| 邮箱 | 单行 | 变更后需重验证（AUM 邮件验证开启时） |
| 头像 | 文件上传/媒体库 | 正方形裁剪后上传，支持 GIF/APNG |
| 网站 | 单行 | 渲染时自动生成链接（自动补全 https://） |
| 描述 | 多行 | 支持 Markdown（标题/粗斜体/代码/链接/列表） |
| 联系方式 | 单行 | 文本展示 |
| 代表作 | 单行 | 文本展示 |

## 设置

后台「多彩个人资料」设置页（需 `colorful-profiles:manage` 权限，超级管理员默认拥有）：

- 头像最大画面边长（px，默认 1024）
- 头像最大文件大小（MB，默认 10）
- 是否允许 GIF 动态头像（默认开）
- 是否允许动态 PNG / APNG（默认开）
- 资料页时间线单次加载数量（默认 10）
- 头像存储目录（默认 `avatars`，即 `./uploads/avatars/`）

## 菜单扩展

其他插件可通过 Hook 向用户菜单追加条目：

```ts
hooks.on('profile:userMenu', (items) => [...items, { title: '我的XX', link: '/my-xx', icon: '✦' }]);
```
